# USER MANUAL

## Project Overview
This is a Maven-based Java project scaffold for Cat Race.

## Project Structure
- `pom.xml`: Maven project configuration.
- `src/main/java/`: Java source code.
- `src/main/resources/`: Application resources (config files, templates, etc.).

## Prerequisites
- Java 17 or later
- Apache Maven 3.9 or later

## Common Commands
From the project root, run:

- Validate project setup:
  ```bash
  mvn validate
  ```
- Compile the project:
  ```bash
  mvn compile
  ```
- Package into a JAR:
  ```bash
  mvn package
  ```

## Next Steps
1. Add your Java classes under `src/main/java/`.
2. Add resource files under `src/main/resources/`.
3. Update `pom.xml` dependencies/plugins as needed.
